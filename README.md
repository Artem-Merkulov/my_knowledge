## Что стоит посмотреть

- **[Алгоритмы JOIN](Algorithms/Joins/)** — реализации `hash join`, `merge join` и `nested loops` на Python. Помогает понять, что происходит под капотом, когда пишешь `JOIN`.
- **[Порядок выполнения операторов SQL](programming_languages/SQL/Порядок%20выполнения%20операторов%20SQL.md)** — почему `WHERE` не видит алиасы из `SELECT`, и где на самом деле выполняется `HAVING`.
- **[Оптимизация SQL запросов](programming_languages/SQL/Оптимизация%20SQL%20запросов.md)** — что смотреть в плане запроса и какие приёмы реально работают.
- **[Свойства таблиц Greenplum](СУБД/Greenplum/Свойства%20таблиц%20GpeenPlum.md)** — распределение, секционирование, сжатие.

## Структура

Заметки лежат по папкам-темам. Внутри папок — файлы `.md` с конспектами, `.py` с реализациями и `.sql` с запросами.
